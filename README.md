# Manzill Pest Control Website

A comprehensive pest control company website designed to provide customers with convenient access to pest control services and easy appointment booking. The website also includes an employee portal for managing work schedules and income tracking.

## 🌟 Features

### For Customers
- **Detailed Service Information**: Comprehensive descriptions of all pest control services including implementation methods
- **Easy Appointment Booking**: Streamlined process for scheduling pest control services
- **Multiple Contact Options**: Phone calls and online contact forms for customer convenience
- **Customer Reviews**: Dedicated review page to showcase service quality and build trust
- **Service Portfolio**: Visual representation of services with before/after images

### For Employees
- **Income Tracking**: View earnings and payment information
- **Work Schedule**: Access upcoming assignments and work schedules
- **Admin Dashboard**: Employee management interface

### Services Offered
- 🐜 **General Pest Control**: Comprehensive pest elimination services
- 🦟 **Common Flies Control**: Specialized fly control and prevention
- 🐭 **Rodent Control**: Professional rodent elimination and prevention
- 💉 **Baiting Services**: Strategic pest baiting solutions
- 🧼 **Disinfection**: Sanitization and disinfection services
- 🏗️ **Pre-Construction Treatment**: Preventive pest control for new constructions
- 🏠 **Post-Construction Treatment**: Post-build pest control solutions
- 🌿 **Soil Treatment**: Ground-level pest prevention
- 💨 **Thermal Fogging**: Advanced pest elimination using thermal fogging
- 🎯 **Residual Spray**: Long-lasting pest control solutions

## 🛠️ Technologies Used

- **HTML5**: Structure and semantic markup for all 16 pages
- **CSS3**: Custom styling and responsive design (`ManzillStyleTest.css`)
- **JavaScript**: Interactive features and admin functionality (`admin.js`)
- **Responsive Design**: Mobile-friendly layout for all devices

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Local web server for optimal performance

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/ManzillPest-main.git
   ```

2. **Navigate to project directory**
   ```bash
   cd ManzillPest-main
   ```

3. **Open in browser**
   - Double-click `index.html` to open in your default browser
   - Or use a local server for better performance:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx http-server
     ```

4. **Access the website**
   - Direct file: Open `index.html` in browser
   - Local server: Navigate to `http://localhost:8000`
